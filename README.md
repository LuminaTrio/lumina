# Lúmina Trio

Bilingual English/German static website for Trio Lúmina GbR.

Open `index.html` in a browser. Photographs are embedded in the HTML. YouTube thumbnails require an internet connection.

## GitHub Pages

In repository Settings → Pages, select Deploy from a branch, branch `main`, folder `/ (root)`, and Save.

## Content

Includes biographies, recordings, concerts, booking contact and bilingual legal dialogs. Unknown legal/hosting details remain marked with `*` and need completion before final public launch.

No build tools or installation required.
